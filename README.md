# Pizzaria Banco de dados

## Objetivo: 

O objetivo é criar e manipular um banco de dados para uma pizzaria, permitindo o cadastro de clientes, pizzas e pedidos, além da criação de relatórios para consultar as informações.

## Tecnologias:
- MySQL
- VsCode
- GitHub

### Comandos:

* SELECT
* INSERT INTO
* UPDATE
* INNER JOIN
* SUM()
* COUNT()
* GROUP BY
* AS
